Mission

Most agents forget everything between calls. Every conversation starts from the same prompt, so the correction a user gave yesterday is lost by tomorrow, and the same mistake comes back.

Fine-tuning can fix that, but it is costly, slow to repeat and ties you to one provider. SIA keeps what an agent learns as readable text instead: short lessons, a playbook and your own documents. You can inspect any of it, veto a lesson you disagree with and roll the playbook back to an earlier version.

How it learns

  1. 01

    Within a task

    Draft, critique against your rubric, revise, keep the best.

  2. 02

    Across tasks

    Short lessons that gain or lose trust based on outcomes; weak ones retire.

  3. 03

    Consolidation

    The playbook is rewritten, then adopted only if it beats the current one on your eval set.

API in 60 seconds

Create an agent, give it a document, ask it something, then correct it. Every call takes your SIA key; calls that use a model also take your own model key, which is used for that request and never stored.

# helper: POSTs when -d is given, GETs otherwise
sia() { curl -s -H "Authorization: Bearer $SIA_KEY" -H "X-LLM-Key: $LLM_KEY" \
  -H "Content-Type: application/json" "localhost:8000$@"; }

# 1. create an agent: its subject, instructions and what a good answer looks like
sia /v1/agents -d '{"name":"tax-bot","domain":"Indian personal income tax",
  "instructions":"Cite the section of the Act. Show calculations.",
  "rubric":"Correct section cited; arithmetic right; flags when a CA is needed."}'

# 2. teach it with a document
sia /v1/agents/$ID/knowledge -d '{"title":"Section 80C","content":"..."}'

# 3. ask it something: it critiques, revises and learns as it works
sia /v1/agents/$ID/run -d '{"task":"Can I claim my PPF under 80C?"}'
# -> {answer, score, episode_id, attempts, critique, lessons_used, new_lessons, llm_calls}

# 4. correct it when it's wrong (kept as pending until you verify it)
sia /v1/agents/$ID/feedback -d '{"episode_id":"...","rating":2,"correction":"..."}'
import os
import httpx

sia = httpx.Client(
    base_url=os.getenv("SIA_URL", "http://localhost:8000"),
    headers={"Authorization": f"Bearer {os.environ['SIA_KEY']}",
             "X-LLM-Provider": "gemini", "X-LLM-Key": os.environ["LLM_KEY"]},
    timeout=120,  # a learning run makes several model calls
)

# 1. create an agent
agent = sia.post("/v1/agents", json={
    "name": "tax-bot", "domain": "Indian personal income tax",
    "instructions": "Cite the section of the Act. Show calculations.",
    "rubric": "Correct section cited; arithmetic right; flags when a CA is needed.",
}).raise_for_status().json()
base = f"/v1/agents/{agent['id']}"

# 2. teach it with a document
sia.post(f"{base}/knowledge", json={"title": "Section 80C", "content": "..."}).raise_for_status()

# 3. ask it something
run = sia.post(f"{base}/run", json={"task": "Can I claim my PPF under 80C?"}).raise_for_status().json()
print(run["answer"])

# 4. correct it when it's wrong
sia.post(f"{base}/feedback", json={
    "episode_id": run["episode_id"], "rating": 2, "correction": "...",
}).raise_for_status()
const BASE = process.env.SIA_URL ?? "http://localhost:8000";

async function sia(path, body) {
  const res = await fetch(BASE + path, {
    method: body ? "POST" : "GET",
    headers: {
      Authorization: `Bearer ${process.env.SIA_KEY}`,
      "X-LLM-Provider": "gemini",
      "X-LLM-Key": process.env.LLM_KEY,
      "Content-Type": "application/json",
    },
    body: body && JSON.stringify(body),
  });
  if (!res.ok) throw new Error(`${res.status}: ${await res.text()}`);
  return res.json();
}

// 1. create an agent
const agent = await sia("/v1/agents", {
  name: "tax-bot", domain: "Indian personal income tax",
  instructions: "Cite the section of the Act. Show calculations.",
  rubric: "Correct section cited; arithmetic right; flags when a CA is needed.",
});

// 2. teach it with a document
await sia(`/v1/agents/${agent.id}/knowledge`, { title: "Section 80C", content: "..." });

// 3. ask it something
const run = await sia(`/v1/agents/${agent.id}/run`, { task: "Can I claim my PPF under 80C?" });
console.log(run.answer);

// 4. correct it when it's wrong
await sia(`/v1/agents/${agent.id}/feedback`, { episode_id: run.episode_id, rating: 2, correction: "..." });
